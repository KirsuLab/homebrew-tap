# KirsuLab Homebrew Tap

Homebrew tap for [KirsuLab](https://kirsulab.com) macOS apps.

## Conduit — Android file manager for Mac

```sh
brew install --cask KirsuLab/tap/conduit
```

Conduit lets you browse, copy, upload and delete your Android phone's files right from your Mac, over USB or Wi-Fi. More: https://kirsulab.com/macos/conduit

## Valpas — keeps your Mac awake

```sh
brew install --cask KirsuLab/tap/valpas
```

Valpas keeps your Mac awake for exactly as long as you say: one switch in the menu bar, a countdown that says when it ends, and rules that start and stop it for you — on the power adapter, with a display attached, or while an app is running. When the time is up it hands your Mac back to its own sleep settings. More: https://kirsulab.com/macos/valpas
